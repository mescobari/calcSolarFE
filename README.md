# Calculadora Modular

Proyecto frontend creado con React, TypeScript y Vite.

## Stack principal
- React + Vite
- TypeScript
- Material UI (MUI)
- React Hook Form
- Zod
- Axios

## Estructura modular por tabs

- Los módulos de cada tab deben ir en `src/tabs/` y se navega entre ellos desde el sistema de tabs en `App.tsx`.

## Scripts principales
- `npm run dev` — Servidor de desarrollo
- `npm run build` — Build de producción
- `npm run preview` — Previsualización del build
